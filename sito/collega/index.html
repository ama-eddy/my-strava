Collega il repo di dati

Report ed editor leggono e salvano il piano e le attività nel tuo repo di dati su GitHub. Servono il nome del repo e un token che può leggerlo e scriverlo.

Come creare il token

  1. Apri GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Dagli un nome, per esempio my-strava, e una scadenza.
  3. Repository access: Only select repositories e scegli solo il repo di dati.
  4. Permissions → Repository permissions → Contents: Read and write. Non serve altro.
  5. Genera il token, copialo e incollalo qui sopra.

Il token resta solo in questo browser: non va sul sito né su GitHub. Chi usa questo browser può modificare il repo di dati, e nient'altro. Puoi revocarlo quando vuoi da Fine-grained tokens. Su ogni dispositivo, computer o telefono, il collegamento si fa una volta.
